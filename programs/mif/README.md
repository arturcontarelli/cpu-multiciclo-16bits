# programs/mif

Arquivos `.mif` usados para inicializar a memória de instrução na simulação e na FPGA. Cada arquivo corresponde a um `.asm` em `programs/asm/` com o mesmo nome — são a tradução binária, não a fonte.

Estes são os arquivos a entregar no Canvas junto com o `.vhd` e o documento de especificação.
